# Upgrade to Umbraco 19

From Umbraco Commerce `[18.0.0, 18.999.999)` (CMS 18) to Umbraco Commerce `19.0.0-beta.1` (CMS `19.0.0-beta1`, tag `release-19.0.0-beta1`).
Branch `v19/topic/cms-19-upgrade` → PR into `release/19.0.0`, both cut from `main` (`21a4c4d`).

**Targets CMS release:** `release-19.0.0-beta1`, via Umbraco Commerce `19.0.0-beta.1` (MyGet `umbracoprereleases`). The package's own version is `19.0.0-beta.1`.

The package depends on `Umbraco.Commerce.Core`, `Flurl.Http` and `System.Runtime.Caching`, never on `Umbraco.Cms.*` directly, so the CMS breaking changes reach it only through Commerce. Commerce's own v19 inventory (Core repo, `docs/upgrades/v19.md`) is the source for those; the Stripe provider's v19 upgrade is the reference run.
